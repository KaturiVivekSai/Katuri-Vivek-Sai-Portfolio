WayMate – Student Ride Sharing Platform

Problem

Students living in PGs, hostels, and nearby college communities frequently face friction and high costs for short-distance travel. Meanwhile, fellow students often commute with empty vehicle seats or keep unused bikes and scooters parked on campus.

Solution

Developed WayMate, a trusted student community mobility platform that connects students needing short-distance rides with peers offering available seats, while also enabling trusted peer-to-peer lending of unused bikes and scooters.

Technologies

React JavaScript HTML CSS Node.js MongoDB json-server Postman

Key Features

  • Ride Discovery & Ride Offering Workflows
  • Community Bike & Scooter Lending
  • Community Credit Wallet System
  • Trust & Safety Verification Features
  • REST API Integration & Postman Validation

Implementation

Built a React-based responsive user interface paired with ride-matching workflows, Community Credit Wallet tracking, and Trust & Safety controls. Implemented backend API endpoints, integrated services using json-server, MSW, and client-side localStorage persistence, and performed manual REST API testing with Postman to validate request/response behavior.

Results

Won 1st Prize at the Frontend Technologies Hackathon conducted by the Department of CSE (AI&ML and Data Science), PVPSIT, and deployed live on Vercel for seamless community access.
